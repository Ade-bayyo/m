# Regal Flower

A modern, attractive landing page for a flower and gifts delivery brand. The project showcases a stylish homepage with a navigation bar, hero section, featured product categories, and gift suggestions for special occasions.

## Project Overview

This website is built as a static front-end project using HTML and CSS. It is designed to look polished and premium, with a floral theme and clear calls to action for customers to browse products and place orders.

## Features

- Visually appealing homepage layout
- Navigation menu with category links and utility icons
- Hero section highlighting flower delivery services
- Featured sections for:
  - fresh flowers
  - forever roses
  - VIP bouquets
  - gift bundles and add-ons
- Floating action buttons for quick customer interaction
- Clean styling with a modern, elegant visual theme
- Responsive design that adapts to different screen sizes

## Responsiveness

The website was designed with responsiveness in mind so that it remains user-friendly on desktops, tablets, and mobile devices. Layout elements such as the navigation bar, content sections, images, and buttons were styled using flexible CSS techniques to ensure the page scales properly across different screen sizes.

## About the Project

This project is a stylish landing page for a flower and gifts delivery brand. It was created to give users a premium browsing experience with a beautiful hero section, featured flower categories, and gift suggestions for different occasions.

The design uses elegant colors, clear layouts, and attractive images from the project image folder to make the page feel welcoming and professional.

A dedicated Plants page was also added so visitors can browse different flowers and plants, search for specific items, and view animated product cards in a responsive layout.

## How to Install from GitHub

1. Open the GitHub repository page for this project.
2. Click the green Code button.
3. Choose one of the following options:
   - Download ZIP to get the project files directly
   - Copy the repository URL if you want to clone it using Git
4. If you are using Git, run:

   ```bash
   git clone <repository-url>
   cd myproject
   ```

5. Open the project folder and launch index.html in your browser.

## How to Run

1. Open the project folder in your preferred code editor.
2. Launch the website by opening index.html in a web browser.
3. To view the new plants page, open plants.html or click the Plants link from the homepage navigation.
4. For a smoother experience, you can also use a live server extension if available.
